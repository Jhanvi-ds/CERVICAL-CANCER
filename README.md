Cervical cancer is one of the most common cancers affecting women worldwide. Early risk assessment can help increase awareness and encourage timely medical consultation. This project presents a machine learning-based Cervical Health Risk Assessment System developed to estimate an individual's risk based on various health-related factors.
Initially, a survey-based approach was considered to collect real-world data from users. However, due to limitations in obtaining a sufficiently large dataset, a publicly available cervical cancer dataset from Kaggle was utilized. The dataset underwent extensive preprocessing, including missing value treatment, outlier removal, exploratory data analysis, and feature selection. Multiple machine learning algorithms including Random Forest, XGBoost, and CatBoost were evaluated. Random Forest demonstrated the most reliable performance and was selected as the final model. The model was integrated into a Streamlit-based web application and deployed using Streamlit Community Cloud for public accessibility.
